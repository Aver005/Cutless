
# Задача: пакет `cutless.camera` — виртуальная камера для слоя-обработки

Слой-обработка (`ClipKind::Layer`) применяет эффекты ко всему, что под ним, но **трансформ у слоя не работает**.
Поэтому наезд, тряска и поворот «сквозь склейки» делаются этим пакетом: агент ставит ключи на его параметры
по долям музыки. Это главный пакет эдитов — делай аккуратно.

## Разрешённые файлы
Только новая папка `src/crates/concat-effects/packages/cutless.camera/` и `locales-camera.json` в корне worktree.

## Манифест — «Camera», category Zoom, `intensity = "zoom"`
| key | диапазон | default | step | unit | что |
|---|---|---|---|---|---|
| `zoom` | 100..400 | 100 | 1 | % | наезд, 100 — как есть |
| `x` | -50..50 | 0 | 0.1 | % | сдвиг картинки по ширине кадра, плюс — вправо |
| `y` | -50..50 | 0 | 0.1 | % | сдвиг картинки по высоте, плюс — вниз |
| `rotation` | -180..180 | 0 | 0.5 | ° | поворот по часовой |
| `tilt` | -30..30 | 0 | 0.5 | ° | наклон плоскости кадра (перспектива), плюс — верх уходит от зрителя |
| `blur` | 0..10 | 0 | 0.1 | % | смаз движения, длина в % ширины кадра |
| `blur_angle` | -180..180 | 0 | 1 | ° | направление смаза |
| `edges` | enum 0/1, labels ["Mirror", "Stretch"] | 0 | — | — | что за краем: отражение или растянутый край |
Все, кроме `edges`, — `animate = true`. Поведение enum посмотри в манифестах с `type = "enum"`.

## Шейдер
1. Координаты: `p = uv - 0.5`, приведи к квадратным единицам (умножь x на `frame.size.x / frame.size.y`), чтобы
   поворот не сплющивал картинку; в конце верни обратно.
2. Обратное отображение (выход → источник), порядок: сдвиг `p -= (x/100, y/100)` (в долях кадра, x — по ширине),
   поворот на `-rotation`, деление на `zoom/100`, затем перспектива наклона:
   плоскость повернута на угол θ = tilt вокруг горизонтальной оси, фокус `f = 1.5` (в высотах кадра).
   Обратная проекция: `Y = py*f / max(f*cos θ - py*sin θ, 1e-3)`, `X = px*(f + Y*sin θ)/f`. При θ = 0 — тождество.
3. Край: `edges == 0` (сравнивай `round(params.edges)`) — `mirror()`, иначе `clamp(q, 0, 1)`.
   Не отдавай прозрачное за краем. Выбор делай через `select()`, не через ветку вокруг `sample()`.
4. Смаз: если `blur > 0` — N отсчётов (N = clamp(ceil(длина в пикселях / 2), 1, 48)) вдоль `blur_angle`
   (угол как у motion-blur: против часовой от горизонта) через `sample_premultiplied` по уже преобразованной и
   отражённой координате, среднее, затем `rgb / max(a, 1e-6)`. При blur = 0 один отсчёт (цикл всё равно можно,
   на N = 1). Никаких `sample()` в цикле.
5. При всех значениях по умолчанию выход должен совпадать с входом с точностью до фильтрации.

## Пробы
По правилам `_common.md`: ровная картинка остаётся собой при любых ручках (зеркальный край). Добавь пробы
`params = { zoom = 250, rotation = 30, x = 20 }` и `params = { tilt = 20, blur = 5, blur_angle = 45 }` с бликом
`[4,1,0.05,1]` и полупрозрачным входом.
