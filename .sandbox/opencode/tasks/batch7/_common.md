# Общие правила (читай внимательно, нарушать нельзя)

Ты — исполнитель в проекте **Cutless**: форк нативного видеоредактора Concat на Rust 2024 + Slint.
Твоя текущая папка — отдельный git worktree с полной копией репозитория. Cargo-workspace лежит в `src/`:
все команды `cargo` запускай из `src/`. Окружение сборки (FFmpeg, libclang, ONNX Runtime) уже выставлено
в переменных среды, общая папка сборки — `CARGO_TARGET_DIR`. Не меняй эти переменные.

Перед работой прочитай: `CLAUDE.md`, `.memories/CONVENTIONS.md`, и код, который будешь менять, целиком.

## Можно
- Менять только файлы, перечисленные в твоей задаче (и создавать новые файлы там, где задача разрешает).
- Запускать `cargo check -p <крейт из задачи>` (можно `--tests`) и `cargo fmt -p <крейт>` из `src/`.
- Читать любые файлы, в том числе исходники зависимостей в `~/.cargo/registry/src/`.

## Нельзя
- `cargo build`, `cargo test`, `cargo clippy`, `cargo run`, запуск приложения — это делает интегратор.
- `git commit`, `git push`, `git checkout`, `git branch`, `git reset`, `git stash` — никаких git-операций, меняющих историю или ветки.
- Добавлять зависимости, кроме явно разрешённых в задаче.
- Трогать файлы вне задачи, переформатировать чужой код, переименовывать то, что не просили.
- `unwrap()`/`expect()` в новом коде вне тестов, `unsafe`, `Result<_, String>` в публичных функциях новых модулей.
- Удалять SPDX-шапки. Новые файлы Cutless начинай с шапки:
  `// SPDX-License-Identifier: AGPL-3.0-or-later` и `// SPDX-FileCopyrightText: 2026 Cutless contributors`.

## Стиль
- В новых файлах Cutless комментарии и doc-комментарии на **русском**, простыми словами, не длиннее двух строк.
- В существующих файлах апстрима — стиль и язык соседнего кода (английский).
- Ошибки — через `thiserror`. Всё повторяющееся — в функцию. Код читаемый без длинных пояснений.
- Пиши юнит-тесты на новую логику (их запустит интегратор).

## Отчёт
В конце обязательно запиши отчёт в файл `{{OUT}}` (на русском):
1. Что сделано (кратко). 2. Список изменённых и созданных файлов. 3. Решения, которые ты принял сам, и почему.
4. Последние строки вывода `cargo check` (успех или ошибки). 5. Что не доделано, риски, вопросы интегратору.
Если не уверен — сделай самый простой корректный вариант и опиши сомнение в отчёте, а не выдумывай.

## Общее для пачки 7: пакеты эффектов для эдитов (TikTok, игровые нарезки)

Ты пишешь **пакеты эффектов** — папки `src/crates/concat-effects/packages/cutless.<имя>/` с тремя файлами:
`effect.toml`, `effect.wgsl`, `fixtures.toml`. Rust не трогаешь. Новые папки создавать можно только свои.
Проверка: `cargo check -p concat-effects` (пакеты встраиваются при сборке; ошибку шейдера найдёт интегратор тестами).

**Сначала прочитай целиком** (это контракт, без него пакет не загрузится):
- `src/crates/concat-effects/src/shader.rs` — строки 1–220 и 520–780: что даёт хост (`sample`, `sample_premultiplied`,
  `frame.size`, `frame.time`, `frame.clip_time`, `texel()`, `hash()`, `exposure()`, библиотеки цвета).
- `src/crates/concat-effects/src/manifest.rs` — поля манифеста, проверки при загрузке, `[[replaces]]`, `[card]`.
- Образцы: `packages/concat.motion-blur/`, `packages/concat.zoom-blur/`, `packages/concat.chromatic-aberration/`,
  `packages/concat.chroma-key/effect.toml` (как пишется `[[replaces]]`), `packages/concat.adjust/effect.toml` (`[card]`).
- Старые удалённые версии твоих эффектов (идея и ручки, **не формат**): `git show 3babe9f^:src/crates/concat-effects/packages/concat.<имя>/effect.toml`
  и `.../effect.wgsl`. Старый формат 1 больше не грузится — пишешь заново в формате 2.

**Обязательно в манифесте:** первая строка `format = 2`; `[effect]` с `id = "cutless.<имя>"`, `name`, `kind = "effect"`,
`category` (только из существующих: Distort, Glitch, Light, Stylize, Color, Blur, Zoom, Retro), `order`, `description`
(одно предложение по-английски), `intensity = "<главный параметр>"`; `[wgsl] entry = "effect.wgsl"`; без `[ffmpeg]`.
У каждого `[[param]]`: `key`, `label`, `min`, `max`, `default` (внутри min..max), `step`, `unit` если есть.
`animate = true` — у всех числовых параметров, кроме `type = "enum"` и `type = "bool"` (им — никогда).
Ключи `intensity` и `index` заняты, параметр так называть нельзя.

**Обязательно в шейдере:**
- `struct Params { ... }` — поле `f32` на каждый параметр в том же порядке, и `fn effect(uv: vec2<f32>) -> vec4<f32>`.
- Работаешь в **линейном свете**: значения выше 1.0 — это блики, их нельзя обрезать. Функции `clamp01` нет.
- **`sample()` нельзя вызывать внутри `if`/ветки, зависящей от пикселя** (это `textureSample`, ему нужна общая ветка).
  Читай `sample()` до любых `if` или используй `sample_premultiplied()` (он без производных; результат
  предумножен на альфу — дели rgb на `max(a, 1e-6)`, как в motion-blur).
- **За краем кадра не отдавай прозрачный пиксель.** Сдвинутую координату отражай зеркалом:
  `fn mirror(q: vec2<f32>) -> vec2<f32> { return vec2<f32>(1.0) - abs(vec2<f32>(1.0) - fract(q * 0.5) * 2.0); }`
- Сдвиги задавай **в процентах кадра**, не в пикселях (кадр бывает и 1080×1920, и 3840×2160).
- Одноразовое (удар, вспышка) делается **ключами параметров**, не временем: на слое-обработке `frame.clip_time` всегда 0.
  `frame.time` годится только для цикла (дрожание, стробоскоп).
- Цвет на выходе — straight alpha; альфу бери у исходного пикселя.

**`fixtures.toml`:** пробы `[[probe]]` (смотри образцы): обязательно `default`, `at = "min"`, `at = "max"` (без `params`),
плюс 1–2 своих с `params = { ... }`. Проба подаёт **ровную** картинку 8×8 одного цвета (`input`), время 0, смотрит
центральный пиксель, допуск 0,4 %. Подбирай вход так, чтобы `expect` считался в уме: у сдвигов и зеркал ровная
картинка остаётся собой; у цветовых — посчитай формулу. Входы: серый `[0.18,0.18,0.18,1]`, блик `[4,1,0.05,1]`,
полупрозрачный `[0.5,0.2,0.1,0.5]`.

**`[[replaces]]`** со старого `concat.<имя>`: `id`, `defaults` — **все** старые ручки с их старыми значениями по
умолчанию, `knobs` — выражения новых ручек через старые. Старые имена в `aliases` **не** клади.

**Переводы.** В локали **не** пиши (их сольёт интегратор). Создай в корне worktree файл `locales-<задача>.json`:
`{ "effects.<имя>.name": { "en": "...", "ru": "...", ... }, "effects.<имя>.description": {...}, "effects.labels.<подпись>": {...} }`
со всеми 25 кодами: ar bn de en es fa fr he hi hr id it ja ko nl pl pt-BR ru th tr uk ur vi zh-Hans zh-TW.
Ключ имени: `cutless.rgb-split` → `effects.rgbSplit.*` (без автора, lowerCamelCase). `effects.labels.<подпись>` нужен
только для новых подписей ручек: сначала проверь `src/crates/concat/locales/en.json` — Amount, Speed, Angle, Shift,
Centre X и многие уже есть. Русский — живой и короткий, как в соседних строках `ru.json`.
