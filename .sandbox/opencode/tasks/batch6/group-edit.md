# Задача: связанные клипы двигаются, режутся, обрезаются и удаляются вместе; Alt — по одному

Клипы с общей меткой группы (`links::link_of`) — видео и его звуковые дорожки. Владелец решил: всё вместе, как в
CapCut; с зажатым **Alt** — действие только над тем клипом, что под рукой, связь при этом не рвётся; пункт меню
клипа «Разгруппировать» (`Command::Unlink`). Обычное «Отделить звук» (без группы) ведёт себя как прежде.

## Что сделать (в `src/crates/concat/src/studio.rs`, найди функции по именам)
1. **Выделение:** клик по клипу группы выделяет всю группу (`with_linked`); с Alt — только этот клип.
2. **Перетаскивание:** набор клипов жеста (`clip_pressed`, `Gesture::Move { origins … }`) расширяется до групп всех
   клипов набора; с Alt — без расширения. Учти комментарий там же про #265: он про обычный detach, его не ломай.
3. **Обрезка края** (жест trim по краю клипа): тот же сдвиг края — всем клипам группы, у которых этот край совпадает
   по времени с краем тянутого (в пределах кадра); одним шагом undo. С Alt — только тянутый.
4. **Резка** (по плейхеду / инструмент «лезвие» / горячая клавиша — найди все места `Command::SplitClips`): к
   разрезаемым клипам добавить их группы; с Alt — без расширения. Модель сама разведёт хвосты в новую группу.
5. **Удаление** (`Command::RemoveClips`, в т.ч. ripple): удаляется вся группа выделенного клипа. Отдельный клип
   группы — только через Alt+клик → Delete (выделение одного) — так и задумано.
6. **Меню клипа:** пункт «Разгруппировать» — виден, когда у клипа есть метка группы; `Command::Unlink`.
   Найди, как строится меню клипа (`MenuItemData`, `menu_target`), и добавь пункт по образцу «Отделить звук».
7. **Состояние Alt:** узнай, как события указателя таймлайна приносят модификаторы (Shift/Ctrl уже где-то
   передаются из `ui/timeline/lanes.slint` в Rust) и протащи Alt тем же путём. Если Alt где-то уже занят —
   опиши в отчёте и не ломай существующее.
8. **Строки:** `clip.ungroup` («Разгруппировать» / «Ungroup») во всех 25 `src/crates/concat/locales/*.json`
   (формат как у `scripts/locales.py`: сортировка, отступ 2, `"_"` первым). Проверка: `python scripts/locales.py --check`.
9. **Тесты:** чистые функции, которые ты вынесешь (например, «набор клипов для действия с учётом Alt и групп»,
   «края группы, совпадающие с тянутым»), — юнит-тесты на маленьком `Project` из `concat_project::Editor`.
