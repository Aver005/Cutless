# Задача: субтитры по словам — короткие читаемые титры вместо одного длинного

Движок распознавания (`src/crates/concat-speech/src/transcribe.rs`) отдаёт `Segment { start, end, text, words: Vec<Word> }`,
у `Word { start, end, text }` таймкоды в секундах от начала окна. Модель Nemotron возвращает всю фразу ОДНИМ сегментом
(16 с речи → один сегмент), и окно субтитров (`src/crates/concat/src/panes/captions.rs`, функция `caption_clip` и
вокруг) делает из каждого сегмента один титр — получается огромная плашка на 16 секунд. Нужно строить титры из слов.

## Что сделать
1. Чистая функция (новый модуль `src/crates/concat/src/panes/caption_lines.rs` или внутри `captions.rs`):
   `fn caption_lines(segments: &[Segment], rules: &LineRules) -> Vec<CaptionLine>` где `CaptionLine { start, end, text }`.
   Правила по умолчанию для вертикального видео: не больше **32 символов** и **2,5 с** на титр; разрыв перед словом,
   если пауза между словами ≥ **0,45 с**; предпочтительный разрыв после `.` `!` `?` `…` (и после `,` если строка уже
   длиннее 18 символов); титр не короче **0,6 с** (растягивать конец до начала следующего, но не дальше); пробелы и
   пунктуация как в исходных словах (слова могут нести ведущий пробел — нормализуй).
   Если у сегмента нет слов — сегмент целиком идёт как сейчас (старое поведение для моделей без таймкодов слов),
   но длинный текст всё равно режь по словам равномерно по времени.
2. Окно субтитров использует `caption_lines` для голоса с таймлайна. Путь «из текста скрипта» не трогать.
3. Тесты: длинная фраза из 30 слов → несколько титров ≤ 32 символов; разрыв на паузе; разрыв после точки;
   минимальная длительность; сегмент без слов; русский текст (кириллица считается по символам, не по байтам!).

## Разрешённые файлы
`src/crates/concat/src/panes/captions.rs`, новый `src/crates/concat/src/panes/caption_lines.rs`,
