## Как

  (issues и PR вместе; у PR есть поле `pull_request`), `.../pulls?state=open`, `.../pulls/<n>/files`,
  `.../issues/<n>/comments`. Учитывай лимит 60 запросов в час — не трать их на лишнее.
- Также просмотри PR, слитые в апстрим после `ef49577`: `git log ef49577..upstream/main --oneline` в репозитории
  (remote `upstream` уже есть; `git fetch upstream` можно).
- Контекст Cutless: `.memories/PRODUCT.md`, `.memories/PLANS.md` (веха M0 — сценарий владельца: вертикальные ролики
  с фронтальной камеры, цвет, звук, паузы, субтитры, агент), `.memories/BUGS.md`.
