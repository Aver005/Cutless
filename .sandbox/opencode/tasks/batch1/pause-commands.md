# Задача: команды пауз в модели проекта (`concat-project`)

Вырезатель пауз: анализ находит паузы → клипы режутся и куски-паузы **помечаются** (не удаляются) → человек
смотрит, возвращает лишнее, подтверждает. Ты делаешь команды документа для этого. Без интерфейса.

Каждая правка документа в Concat — вариант `enum Command` в `src/crates/concat-project/src/commands/mod.rs`
(`#[serde(tag = "op", rename_all = "camelCase", rename_all_fields = "camelCase")]`), каждая команда = один шаг undo.
Изучи `commands/mod.rs`, `commands/clips.rs` (как устроены `SplitClips`, `MergeClips`, `RemoveClips{ripple}`,
`close_gaps`), `commands/audio.rs` (что такое `detached_from`), модель `Clip` в `model.rs` (поле `extra` — карта
неизвестных полей, которая сохраняется в `concat.json`).

## Разрешённые файлы
- `src/crates/concat-project/src/commands/mod.rs` — только: новые варианты `Command`, маршрутизация в `apply`,
  объявление модуля. Существующие варианты и их поведение не менять.
- Новый файл `src/crates/concat-project/src/commands/pauses.rs` — вся логика.
- Тесты — в `pauses.rs` (`#[cfg(test)]`).

## Пометка паузы
Хранится в `clip.extra["cutless"]["pause"] = true` (объект `cutless`, чтобы потом класть туда другие поля Cutless).
Публичные функции в `pauses.rs`: `pub fn is_pause(clip: &Clip) -> bool`, и внутренняя установка/снятие.
При снятии пометки удаляй ключ `pause`, а пустой объект `cutless` — целиком (чтобы документ не захламлялся).

## Команды
1. `MarkPauses { clip_id: String, ranges: Vec<PauseRange> }` — `PauseRange { start: f64, end: f64 }` в секундах
   **таймлайна** (абсолютные). Режет клип по всем границам отрезков **в порядке убывания времени** (иначе вторые
   разрезы промахиваются — см. как `SplitClips` выдаёт id хвосту) и помечает куски, лежащие внутри отрезков.
   Вместе с клипом режь и помечай его отсоединённый звук (клипы с `detached_from == clip_id`) по тем же границам.
   Отрезки вне клипа обрезай по его границам; пустые игнорируй.
2. `SetClipPause { clip_ids: Vec<String>, on: bool }` — пометить/снять пометку.
3. `RestorePauses { clip_ids: Vec<String> }` — снять пометку и **склеить кусок обратно** с соседями, если они на той
   же дорожке, вплотную по таймлайну и продолжают тот же медиафайл без разрыва (`source_start` соседа совпадает
   с концом куска с учётом скорости). Используй существующую логику склейки (`MergeClips`), если она подходит.
4. `ConfirmPauses { clip_ids: Option<Vec<String>> }` — `None` = все помеченные на активном таймлайне. Удаляет
   помеченные куски и сдвигает влево всё, что после каждого вырезанного отрезка времени, **на всех дорожках, кроме
   музыки**. Музыка = клип вида `Audio` без `detached_from` (фоновый трек) — его не режь и не двигай.
   Текстовые клипы и прочие наложения на других дорожках: целиком внутри вырезанного отрезка — удалить; частично
   пересекают — укоротить на пересечение; после отрезка — сдвинуть влево. Обрабатывай отрезки от последнего к первому,
   чтобы сдвиги не сбивали координаты. Всё — одна команда, один шаг undo.

## Тесты
Разметка клипа с двумя паузами (проверить число кусков, пометки, `source_start` кусков); разметка вместе с
отсоединённым звуком; снятие и склейка обратно; подтверждение: длина таймлайна уменьшилась на сумму пауз, текст
после паузы сдвинулся, текст внутри паузы удалён, музыка не тронута; сериализация команд в JSON (`"op": "markPauses"`).
