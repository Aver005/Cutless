# DECISIONS
> Решения с причинами. Не пересматривать без новых данных. Last updated: 2026-10-16.

## Продукт и форк (2026-10-16)

- **Имя продукта — Cutless.** Выбрано владельцем. «Concat» как имя и логотип использовать нельзя
  (`docs/upstream/TRADEMARK.md` апстрима). Допустимая формулировка — «a fork of Concat». Формальная проверка
  товарного знака не проводилась (`PLANS.md`, Р1).
- **Основа — форк Concat, а не развитие ki-video.** ki-video по возможностям — малое подмножество
  Concat, на другом языке и с другим рендером. Из него переносим идеи, не код (`reference/DONORS.md`).
- **Мягкий форк.** Апстрим очень быстрый (сотни коммитов в месяц), жёсткий форк сгниёт за месяцы.
  Регулярно забираем апстрим, своё держим в отдельных крейтах (`reference/UPSTREAM.md`).
- **Вклад в апстрим откладываем** до заметного роста Cutless (владелец, 2026-10-16): «не делать бесплатную
  работу». Синхронизацию с апстримом продолжаем, кандидаты в PR только записываем.
- **Пушит только владелец.** Агент коммитит локально и не пушит, даже если раньше разрешали (2026-10-16).
- **Приоритет №1 — сценарий владельца M0 «Мой TikTok»** (`PLANS.md`): цвет, звук, паузы, субтитры, агент.
- **Лицензия Cutless — AGPL-3.0-or-later**, как у апстрима. Перелицензировать чужой код нельзя: CLA
  апстрима — лицензия в пользу мейнтейнера, а не нам. Монетизация строится с учётом этого
  (`reference/MONETIZATION.md`).

## Интерфейс (2026-10-16)

- **Коммит апстрима `bdcaedf` (ClearType) в Cutless откатан**: с ним окно не запускается на Windows с видеокартой
  (`BUGS.md`). Вернуть, когда апстрим починит, — проверять запуском окна на машине владельца.

- **Остаёмся на Slint, на веб не переписываем.** Кадр превью — текстура wgpu на общем с окном
  устройстве, без копирования в память. Webview такую текстуру не примет: пришлось бы гнать
  ~250 МБ/с кадров через IPC или накладывать нативную поверхность под прозрачный webview. Кроме того,
  переписывание — это ~55 тыс. строк и жёсткий форк.
- **Всё в одном приложении, без отдельных веб-интерфейсов.** Новое (агент, рецепты, очередь задач)
  делается окнами и панелями Slint в едином стиле. Несколько окон верхнего уровня Slint поддерживает:
  каждый компонент `inherits Window` показывается своим `show()` (сверено с документацией 1.18).
- **Свой внешний вид — через тему, а не через переписывание виджетов.** Цвета живут только в
  `ui/theme/`, виджеты — в `ui/primitives/`. Новые компоненты строим из тех же примитивов.
- **Интерфейс тестируем через `i-slint-backend-testing`.** Это бэкенд без окна: `ElementHandle`,
  поиск по `accessible-label`, клики, подменённое время. Для этого контролам нужны `accessible-label` → апстрим.

## ИИ-слой (2026-10-16)

Подробный проект — `reference/AI-LAYER.md`.

- **Агент правит проект только командами `concat_project::Command`.** Прямой записи в `concat.json`
  не бывает. Так работают undo, проверки и живое обновление окна.
- **Один реестр инструментов, два лица.** Одни и те же инструменты видит встроенный агент (внутри
  процесса) и внешние агенты через MCP. Описания и проверки пишутся один раз.
- **Сначала работа без окна, потом мост к экрану.** MCP поверх собственной сессии API отлаживается
  без `studio.rs`. Мост «агент правит проект на экране» — отдельная фаза.
- **Ход агента — один шаг undo.** Правки хода собираются в `Batch` или жест. Ctrl+Z откатывает ход целиком.
- **Сначала текст, потом картинка.** Всё, что агент «видит», есть в виде текста: сводка таймлайна,
  транскрипт, сетка долей, проверки. Причина — модели без зрения (DeepSeek Web). Кадры и
  контакт-листы — дополнение для моделей со зрением.
- **Встроенный агент нужен**, внешнего через MCP мало. Подписке нужен агент, который работает без
  установки Claude Code и прочих. Внешние агенты — через MCP, а потом через ACP.
- **Без tokio в ИИ-слое.** Concat живёт на потоках («threads, not async»), tokio только за фичей gRPC.
  HTTP к LLM — блокирующий `ureq` (уже в `concat-host`) в потоке `host::spawn`, стрим SSE читается построчно.
- **pooprusteek не встраиваем как библиотеку на старте.** Крейт только бинарный, а `fastembed` тянет
  `ort` rc.12 при `ort =rc.13` у Concat (одинаковый `links`). Подключаем его как внешнего MCP-клиента.
  Парсер вызовов инструментов (`tool_parser`) можно позже вынести в общий крейт.
- **Провайдеры LLM — сначала OpenAI-совместимый.** Один протокол покрывает OpenRouter, DeepSeek API,
  Ollama, LM Studio, свой будущий сервер подписки. Anthropic и Gemini — следом. Список держим
  нейтральным: ни к кому не привязываемся.

## Монтаж (2026-10-16)

- **Новые сущности проекта сначала живут в `extra`.** Формат апстрима заморожен на
  `DOCUMENT_VERSION = 1`, а неизвестные поля Concat сохраняет как есть. Сетку долей и метаданные рецепта
  кладём в `extra` под префиксом `cutless.`, пока не договоримся с апстримом о версии.
- **Анимации текста возвращаем как пакеты эффектов с ключами, а не как поля клипа.** Апстрим
  сознательно удалил старые поля `animationIn/Out/Combo/Loop`. Пакеты — их же механизм расширения, он
  не конфликтует с моделью.

## Процесс (2026-10-16)

- **Язык.**
  - Наши крейты: комментарии и документация на русском, не длиннее двух строк.
  - Файлы апстрима и ветки `up/*`: английский, как у соседнего кода, чтобы правку можно было отдать.
  - `.memories/`: на русском.
- **Коммиты Cutless — по правилу владельца** (копия — `CONVENTIONS.md`; оригинал в `.trae/`, которая в git не идёт): эмодзи, тело Keep a
  Changelog, не больше одного scope. **PR в апстрим — в их стиле** (`feat(scope): ...`, без эмодзи) и с `-s`.

## Агент: решения владельца (2026-10-16, утро)

- **Порядок:** MCP-сервер → мост к открытому окну → встроенный чат на тех же инструментах.
- **Модели встроенного чата первой волны:** OpenAI-совместимые (OpenRouter, DeepSeek API, Ollama, LM Studio, свой
  сервер), DeepSeek Web через pooprusteek, Anthropic (Claude).
- **Правки агента применяются сразу**, ход агента = один Ctrl+Z. Удаление медиа и экспорт поверх файла — с вопросом.
- **Первые сценарии:** субтитры в стиле X; паузы и чистка звука; поиск по смыслу (по транскрипту).
- **Каркас `cutless-tools`** заложен интегратором: трейт `Editor` (API без окна → позже окно), `Tool`, `Registry`,
  модули `edit` / `speech` / `pauses` — по одному на исполнителя.
