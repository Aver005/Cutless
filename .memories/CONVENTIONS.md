# CONVENTIONS
> Правила кода, коммитов и веток. Last updated: 2026-10-16.

## Инварианты (нарушать нельзя)

1. **Документ меняется только через `concat_project::Command`.** Ни агент, ни рецепт, ни новый код не
   пишут `concat.json` напрямую.
2. **Ход агента и запуск рецепта — один шаг undo.**
3. **Агент не получает весь документ.** Только компактные сводки, детали и diff.
4. **Правки агента идут через ту же политику подтверждений**, никаких «тихих» удалений и перезаписи файлов.
5. **Ключи API никогда не попадают** в проект, логи, ответы инструментов и журнал.
6. **Движок апстрима не зависит от крейтов Cutless.** Стрелки только сверху вниз.
7. **Потоки, не async.** Никакого tokio в новом коде; тяжёлое — `host::spawn`, в UI — `invoke_from_event_loop`.
8. **Строки интерфейса только через `I18n.t` / `t()`**, русский и английский обязательны.
9. **Новые контролы — с `accessible-label`.** Это доступность и опора для тестов.
10. **Цвета только из `ui/theme/`.** Новые компоненты — из `ui/primitives/`.
11. **Время в документе — секунды**, внутри движка — `Rational`. Не плодить третье представление.
12. **Новые зависимости — только с разрешения владельца** (Р10 в `PLANS.md`).

## Код

**Унаследовано от апстрима** (`CONTRIBUTING.md`, `src/README.md`), действует везде:
- Rust 2024, `rustfmt` с `max_width = 100`, `clippy -D warnings`, `missing_docs = "warn"`.
- Логи — только `log::info!/warn!/error!`, не stdout. Уровень — `CONCAT_LOG=debug`.
- Ссылки внутри графов — handles в арене, а не указатели. Generics неглубокие.
- Ошибки — типизированные через `thiserror`.

**В крейтах `cutless-*`:**
- Ошибки — свои `thiserror`-типы, без `Result<_, String>` в публичных функциях.
- Без `unwrap`/`expect` вне тестов. Исключение — инвариант, который записан рядом в комментарии.
- Без `unsafe`.
- Всё, что повторяется больше одного раза, выносится в функцию или тип. Обходов системы типов нет.
- Комментарии и doc-комментарии **на русском**, простыми словами, не длиннее двух строк. Если коду нужен
  длинный комментарий, код переписывается.

**В файлах апстрима:** точечные вставки, стиль и язык комментариев — как у соседнего кода
(английский). Без попутного форматирования и переименований: каждая лишняя строка — будущий конфликт.

## Гейт перед коммитом

```
cd src
cargo fmt --check
cargo clippy --all-targets -- -D warnings
cargo test
python3 ../scripts/locales.py --check     # если тронуты строки интерфейса
python3 ../scripts/models.py --check      # если тронуты модели
```

Pre-commit hook — Ф0.6. Коммит только из документации (`.memories/`, `*.md`) гейт Cargo не требует.

## Коммиты Cutless

Правило владельца (у него оно ещё лежит в `.trae/rules/git-commit-message.md`, но эта папка в git не
попадает, поэтому правило продублировано здесь):

- Тема: `<type>(<scope>)!: <emoji> <Description>` на английском.
  - Типы: `feat`, `fix`, `hotfix`, `chore`, `refactor`, `release`, `docs`, `test`, `build`, `ci`, `style`, `perf`.
  - Scope — ровно один или ни одного: строчные буквы, цифры, точки, дефисы.
  - `!` — ломающее изменение.
  - Описание с заглавной буквы, перед ним эмодзи.
- Тело после пустой строки — разделы Keep a Changelog: `### Added`, `### Changed`, `### Deprecated`,
  `### Removed`, `### Fixed`, `### Security`. В каждом — список для людей, без пустых разделов.
- Нельзя начинать с `wip`, `tmp`, `fixup!`, `squash!`, `Merge branch`.
- Никаких подписей об авторстве ассистентов и инструментов.

Пример:

```
feat(mcp): 🤖 Add stdio MCP server over the editor API

### Added
- `concat-cli mcp` serves the tool registry over stdio
- Timeline summary tool with clip ids and revision
```

## Коммиты для PR в апстрим

Ветки `up/*` пишутся в стиле апстрима: `feat(api): an MCP transport over the API`. Без эмодзи и без
тела Keep a Changelog. **Каждый коммит с `-s`** (`Signed-off-by` по их `CLA.md`). Подробно —
`reference/UPSTREAM.md`.

## Ветки

- `main` — зеркало апстрима, своих коммитов нет.
- `develop` — Cutless, ветка по умолчанию.
- `feat/*`, `fix/*` — от `develop`.
- `up/*` — от `upstream/main`.

Имена веток на английском. Пушит владелец; агент не пушит и не трогает удалённые репозитории без
явного разрешения в текущем разговоре.
