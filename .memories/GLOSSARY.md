# GLOSSARY
> Термины Concat и Cutless, по строке на каждый. Last updated: 2026-10-16.

## Concat (апстрим)

| Термин | Значение |
|---|---|
| **Апстрим** | Исходный репозиторий jub0t/concat, от которого сделан форк |
| **Command** | `concat_project::Command` — одна сериализуемая правка документа (`{"op": "splitClips", ...}`) |
| **Batch** | Команда-группа: применяется целиком или никак, один шаг undo |
| **Outcome** | Результат команды: `created_id`, `applied` |
| **ClipPatch** | Частичная правка свойств клипа в `UpdateClip`. Цепочки эффектов заменяет **целиком** |
| **Жест (gesture)** | Серия команд одного действия (поворот ручки, перетаскивание), склеенная в один шаг undo: `apply_within` / `end_gesture` |
| **Эхо (echo)** | Клон документа, по которому окно рисует перетаскивание до фиксации команды |
| **Session** | Открытый проект в `concat-host`: документ + undo + настройки. `Session::apply` → `EditorView` |
| **EditorView** | Ответ на правку: весь проект + `can_undo/can_redo` + `created_id` |
| **Studio** | Контроллер окна (`studio.rs`): принимает `Msg`, применяет команды, публикует данные в Slint |
| **Pane** | Панель окна по схеме state + `Msg` + `update` + `data` (`panes/*.rs`) |
| **publish** | Пересборка моделей Slint из состояния `Studio` после изменения |
| **epoch** | Номер поколения проекта; результаты фоновых задач для старого проекта отбрасываются |
| **SingleFlight** | Защита от двойного запуска долгой задачи одного вида (`concat-host/src/jobs.rs`) |
| **OpenProjects / Holder** | Реестр открытых проектов: кто держит проект — окно или API. Не даёт API править проект на экране |
| **Hub** | Поток в `concat-server`, который владеет `Api` и обрабатывает вызовы по очереди |
| **FramePlan** | План кадра в момент `t` (геометрия, маски, фейды) — вход GPU-композитора |
| **Пакет эффекта** | Папка `effect.toml` + `effect.wgsl` (картинка) или шаблон цепочки FFmpeg (звук). Фильтры, эффекты, переходы, аудио |
| **Слот / шаблон** | Проект-заготовка с местами под медиа (`FillSlot`, `template.instantiate`) |
| **Прокси** | Уменьшенная H.264-копия тяжёлого исходника, только для воспроизведения |
| **Filmstrip** | Лента миниатюр клипа на таймлайне |
| **Rational** | Точное рациональное время движка; в документе время хранится в секундах `f64` |
| **extra** | Неизвестные поля `concat.json`, которые Concat сохраняет и записывает обратно. Там живут данные Cutless |
| **Remote** | Страница настроек окна, которая поднимает API-сервер внутри приложения |

## Cutless

| Термин | Значение |
|---|---|
| **Cutless** | Имя форка и продукта. Читается как cut less («режь меньше») и созвучно cutlass (абордажная сабля) |
| **ИИ-слой** | Всё, что даёт агентам монтировать: реестр инструментов, MCP, мост к окну, встроенный агент |
| **Инструмент (tool)** | Операция для агента в `cutless-tools`: имя, описание, схема входа, обработчик |
| **Сводка таймлайна** | `timeline_summary` — компактное текстовое описание проекта для модели, по строке на клип |
| **Ревизия** | Номер версии документа. Правка с устаревшей ревизией отклоняется |
| **Мост** | Путь, по которому правка агента применяется к проекту на экране через `Studio::apply` (Ф3) |
| **Ход агента** | Один ответ агента на запрос пользователя со всеми вызовами инструментов. Откатывается одним Ctrl+Z |
| **Политика подтверждений** | Какие вызовы агента выполняются сами, а какие ждут «да» пользователя |
| **BYOK** | Bring your own key — агент работает на ключе пользователя, без подписки |
| **Рецепт** | Переносимый сценарий монтажа: входы, шаги (вызовы инструментов и задания агенту), ассеты, стили. Запускается на новом материале |
| **Пакет стилей** | Токены бренда + сюжетный конфиг, из которых строятся сцены (как Reglament и NightShift в `promo-reel`) |
| **Сетка долей** | bpm, фаза и удары трека, хранятся в проекте (`cutless.beats`). К ним прилипают склейки и анимации |
| **Удар (hit)** | Онсет в треке с силой по полосам: бочка, малый, общий |
| **Контакт-лист** | N кадров проекта в одной картинке с подписями времени — «глаза» агента со зрением |
| **Рефрейм** | Перевод горизонтального кадра в вертикальный (9:16) с панорамой и зумом по ключам |
| **Безопасные зоны** | Области кадра, которые закрывает интерфейс площадки (TikTok: сверху, снизу, справа) |
| **Донор** | Проект, из которого Cutless берёт идеи: ki-video, econcar/`promo-reel`, pooprusteek |
| **MCP** | Model Context Protocol — открытый протокол, по которому внешний агент вызывает инструменты Cutless |
| **ACP** | Agent Client Protocol — протокол, по которому приложение запускает внешнего агента и показывает его работу |
| **Мягкий форк** | Форк, который регулярно забирает апстрим и отдаёт ему общие улучшения |
| **Cutless Pro** | Рабочее имя будущей подписки (`PRODUCT.md`) |
