# LEARNINGS
> Грабли и неочевидные факты. Last updated: 2026-10-16.

Факты собраны чтением кода апстрима `v0.2.7-21-gef49577`. Что проверено только чтением, а не запуском,
помечено `[?]`.

## Сборка

- **`cargo` только из `src/`.** Корень git — не корень Cargo; из корня команды падают с непонятными
  ошибками путей.
- **`FFMPEG_DIR` задаётся в окружении машины, не в `src/.cargo/config.toml`.** Комментарий в этом файле
  прямо запрещает: путь машины в репозитории ломает чужие сборки.
- **На Windows DLL FFmpeg должны быть в `PATH`**, иначе тесты и окно не стартуют. Сборка — BtbN `win64-gpl-shared` `[?]`.
- **`.slint` компилируется в потоке со стеком 512 МБ** (`src/crates/concat/build.rs`). На Windows
  компилятор Slint иначе падал с переполнением стека. Не «упрощать».
- **Обновление Slint = ручной перенос патча** `src/patches/i-slint-renderer-skia` (ClearType, глифы).
  Без переноса текст на Windows станет мыльным.
- **`cargo dev`** = `run --bin concat --profile quick`. Движок с оптимизацией, окно без, инкрементально.
  Первый билд — минуты, это нормально.

## API и команды

- **README апстрима обещает MCP, а его нет.** Есть только комментарий в `concat-api/src/lib.rs`, что
  MCP — будущий транспорт. Это наша Ф2.
- **API-сервер не правит проект, открытый в окне.** Так задумано (`OpenProjects`/`Holder`). Для живой
  работы агента нужен мост (Ф3), а не «просто включить Remote».
- **`edit.apply` возвращает весь `Project`.** Для агента это дорого по токенам: нужны компактные ответы.
- **`UpdateClip` заменяет цепочки `filters`/`video_effects` целиком**, а `SetEffectKey` адресует эффект
  по индексу. Агент с устаревшим состоянием затрёт чужие эффекты. Лечится ревизиями и id (Ф2.3, Ф2.4).
- **Экспорт через API всегда VBR и без выбора аппаратного энкодера.** CBR и аппаратный выбор есть только в окне.
- **`concat-cli serve` по умолчанию пишет только в домашнюю папку** (`--root`), токен печатает при
  старте или берёт из `CONCAT_API_TOKEN`.
- **JSON-схем для `Command` нет** (`schemars` не подключён). Схемы инструментов придётся писать или
  генерировать — новая зависимость (Р10).

## Модель документа

- **Типов дорожек нет**, все универсальные. «Главной дорожки», как в CapCut, тоже нет.
- **Субтитры — обычные текстовые клипы** (`AddTextClip` пачкой в `Batch`), отдельной дорожки нет.
- **Whisper отдаёт сегменты без времени слов** (`Segment {start, end, text}`). Караоке и монтаж по
  словам требуют доработки (Ф5.5) `[?]`.
- **Анимации текста апстрим удалил сознательно:** `drop_retired_fields` вычищает старые поля при
  открытии проекта. Возвращать их полями клипа нельзя — только пакетами (`DECISIONS.md`).
- **`DOCUMENT_VERSION = 1` заморожен**, миграции формы клипов не решены. Новые данные — в `extra`.
- **Переход хранится на клипе** (`transition_in`), а не между клипами.

## Идентичность

- **`IDENTIFIER = "app.concat.editor"` определяет пути данных.** Пока он не сменён, Cutless и Concat
  делят настройки, кэш и проекты пользователя (`reference/REBRAND.md`).
- **Модели и обновления идут с репозитория апстрима**, пока не сменены `REPO` в `models.rs` и `updates.rs`.

## Агенты и внешние проекты

- **У DeepSeek Web нет зрения**, а MCP-клиент pooprusteek сводит картинку к `[Image: mime]`. Всё
  важное для агента должно быть доступно текстом.
- **pooprusteek и Concat конфликтуют по `ort`** (rc.12 через `fastembed` против `=rc.13`, одинаковый
  `links = "onnxruntime"`). В один граф Cargo без доработки не собрать.
- **`--acp` у pooprusteek — не ACP**, а самодельный ретранслятор без инструментов.

## Окружение и инструменты

- **`gh` на машине владельца не установлен** (2026-10-16). Данные о репозиториях — через
  `curl https://api.github.com/repos/...`.
- **Линтер базы знаний** (расширение владельца `dot-memories-ext`):
  - знает только статусы `DONE`, `WIP`, `TODO`, `BUG`, `IDEA`, `?`, `CRITICAL`, `HIGH`, `MEDIUM`, `LOW`;
  - текст после `→` принимает за ссылку на файл или символ;
  - номера строк (`→ path:line`) допускает только в `BUGS.md` и `reference/`.

  Свои статусы и стрелки в прозе дают предупреждения.
