# PLANS
> Дорожная карта Cutless. Last updated: 2026-10-16 (добавлена M0 «Мой TikTok»; вклад в апстрим отложен).

План разбит на фазы. Каждая фаза — законченный результат, которым можно пользоваться. У каждой фазы
есть критерий готовности. Задачи внутри фазы помечены статусом и номером (`Ф2.3`), чтобы на них
ссылаться из журнала и коммитов. Устройство ИИ-слоя — `reference/AI-LAYER.md`, откуда что берём —
`reference/DONORS.md`.

## M0. Мой TikTok — главный сценарий владельца (приоритет №1)

> Добавлено 2026-10-16. Всё, что ниже в этом файле, идёт после M0 или вплетается в него.

**Сценарий.** Вертикальное видео на фронтальную камеру OnePlus Nord 5G при домашнем свете → цвет, чистый
звук, вырезанные паузы, субтитры, агент помогает → экспорт для TikTok. Сейчас владелец делает это в других
программах. M0 готова, когда он делает это целиком в Cutless.

Что уже есть в Concat (проверено по коду 2026-10-16) и чего не хватает:

| Блок | Есть | Нет |
|---|---|---|
| **Цвет** | `concat.adjust`: температура, тинт, экспозиция, контраст, светá, тени, белые, чёрные, lift/gamma/gain, насыщенность, резкость. Плюс Color Wheels, Curves, White Balance, 57 готовых лутов, импорт `.cube`, ключи на любом параметре | Скопы (гистограмма, waveform, вектороскоп). Шумодав видео (`hqdn3d`, `nlmeans` уже в разрешённом списке FFmpeg `concat-effects/src/filters.rs`). «Мой грейд» одной кнопкой на все клипы. Автокоррекция |
| **Звук** | Noise Reduction (`afftdn`), Enhance Voice (highpass 80 Гц + шумодав + де-эссер + компрессор + лимитер), Normalize Loudness, Bass, Treble и ещё 20 эффектов. Аудиопакет — шаблон цепочки FFmpeg в TOML, Rust не нужен | Срез низов и верхов с выбором частот. Шумовой гейт (`agate` разрешён). VST |
| **Паузы** | — | Всё: поиск пауз, отступы до и после, предпросмотр, вырезание одним шагом undo |
| **Субтитры** | Окно Captions: whisper (6 моделей) по голосу клипа или по тексту, пачка титров одним undo, стили титров | Пресеты стилей субтитров. Таймкоды по словам (караоке). Импорт и экспорт SRT. Проверка русского `[?]` |
| **Агент** | API-команды на всё перечисленное (`reference/AI-LAYER.md`) | MCP, мост к окну, панель агента, «справочник программы» для агента |

## Сквозные задачи (всегда)

- **Синхронизация с апстримом** раз в несколько дней (`reference/UPSTREAM.md`). Тяжёлые слияния — в журнал.
- **PR в апстрим отложены** до заметного роста Cutless (решение владельца 2026-10-16). Кандидаты копятся в `reference/UPSTREAM.md`.
- **Тесты на каждую фичу:** движок — `cargo test`, интерфейс — `i-slint-backend-testing`, ИИ-слой — поддельный провайдер.
- **i18n:** ни одной строки интерфейса мимо `I18n.t`. Русский и английский обязательны.
- **Доступность:** `accessible-label` на всех новых контролах. Это же нужно для тестов.
- **Производительность:** правки агента не блокируют поток UI, тяжёлое — через `host::spawn`.
- **База знаний** обновляется в той же сессии, что и код (`INDEX.md` → Правило обслуживания).
