# PAUSES — вырезатель пауз (M0.4)
> Проект по идее владельца и разбору кода. Last updated: 2026-10-16 (проект, кода нет; есть открытые вопросы).

## Идея владельца

Не резать молча. Сначала разметить паузы, показать их, дать проверить и только потом удалить.

1. Включаешь инструмент. Пороги по умолчанию «средние по больнице» или вычисляются из звука файла:
   где шумовой пол, где речь.
2. По краям каждой паузы остаётся отступ, по умолчанию 1/3 с.
3. «Разметить» режет клип(ы) на куски, а куски-паузы помечает на таймлайне красным (вуаль, рамка,
   зачёркивание). Ничего не удаляется.
4. В плеере переключатель **«Оригинал / Без пауз»**: во втором режиме помеченное пропускается.
5. Клик по паузе возвращает её или снова отмечает. Кнопки «Подтвердить все», «Подтвердить оставшиеся»,
   «Вернуть все». Подтверждение — ripple-удаление одним шагом undo.

## Проект

**Данные.** Отметка — `clip.extra["cutless"]["pause"] = true`. Новые команды в `concat-project`:
- `MarkPauses { clip_id, ranges }` — режет по убыванию времени и ставит отметку. Один шаг undo.
  Отсоединённый звук режется вместе с видео.
- `SetClipPause { clip_ids, on }` — вернуть или снова отметить.

**Анализ** (свой модуль, без окна):
1. Громкость RMS окнами по 20 мс через `AudioDecoder`, с цепочкой фильтров клипа: анализ слышит то же,
   что и пользователь.
2. Автопорог: гистограмма громкости → шумовой пол и уровень речи → порог между ними.
3. Отрезки тише порога дольше минимальной длины → минус отступ с каждой стороны.
4. Клипы с `speed_curve` не анализируем (отказ с понятным текстом).

**Подтверждение.** `Batch[RemoveClips{отмеченные, ripple}, фейды 10–20 мс у соседей]` — id уже известны.

**Предпросмотр «Без пауз».**
- v1 — прыжок в таймере окна: позиция попала в отмеченный отрезок → `seek` на его конец. Около 20 строк,
  движок не трогаем.
- v2 — производный проект без пауз для звука и превью. Делаем, если в v1 будут подвисания на стыках.

**UI.**
- Окно параметров: порог (авто или вручную), минимальная пауза, отступ, кнопка «Разметить».
- Немодальная полоса «N пауз · Подтвердить все · Подтвердить оставшиеся · Вернуть все · Выйти».
- Красная вуаль + рамка + зачёркивание на клипе-паузе, клик переключает.
- Переключатель «Оригинал / Без пауз» в панели превью.

**Для агента (Ф2):** инструменты `analyze_pauses`, `mark_pauses`, `confirm_pauses`.

## Открытые вопросы к владельцу

1. **Какие дорожки сдвигать при подтверждении.** Ripple двигает только дорожку с удалениями, поэтому
   титры и музыка на других дорожках разъедутся. Варианты: сдвигать всё (кроме музыки?) или только эту
   дорожку.
2. **Порядок работы.** Рекомендация: сначала паузы, потом субтитры — тогда титры не нужно двигать.
3. **«Вернул паузу» — склеивать куски обратно** при выходе из режима или оставить разрезы?
4. **Минимальная длина паузы по умолчанию** — предложение 0,5 с (уже после отступов).
5. **Область анализа:** выделенные клипы или все клипы со звуком.
