# BEATS — сетка долей (Ф5.2)
> Что сделано и как устроено. Last updated: 2026-10-17 (анализ, хранение, агент, окно, правки ревью; окно руками не проверено).

Цель: «эдит под трек» по музыке. Анализ трека → темп, фаза, такты, бочки, малые, дропы → риски на клипе,
прилипание к долям, удары `hit_fx` по долям. Донор — econcar `tools/audio.py`; у донора есть подсказка темпа,
у нас нет. Перед кодом — аудит трёх агентов (DSP, хранение, окно), после — ревью панели моделей.

## 1. Анализ — крейт `cutless-beats` (без FFT и новых зависимостей)

- **Звук:** весь файл, моно 16 кГц, читается потоком (`next_f32`), в памяти — по числу на шаг и полосу. Цепочка
  фильтров клипа не берётся (время — файла). Флаг остановки между кусками.
- **Огибающие** (`envelope.rs`, шаг 5 мс): полосы биквадами — всё (ВЧ 20 Гц), бас (ВЧ 30 Гц 2-го + НЧ 150 Гц
  4-го порядка), середина (ВЧ 1,2 кГц 4-го + НЧ 6 кГц 2-го); мощность по шагу, окно Ханна (бас 25 мс, прочее 15 мс),
  `ln(1 + C·e)`, `C = 1000/P95`, положительная разность, деление на P99,5. Онсет опережает удар на полшага —
  `LEAD` = 5 мс прибавляется к фазе и ударам.
- **Темп** (`tempo.rs`): автокорреляция суммы трёх онсетов (минус скользящее среднее за 1 с), вес логнормальный
  вокруг 120 BPM, пик уточняется параболой. Кандидаты ×{1, 2, ½, 3/2, 3/4, 2/3, 4/3} в 60…200, счёт `metrical`:
  насколько доли выше среднего по треку + опора на полудоли (½ веса, не больше половины долей) − штраф, если полудоли
  почти как доли (значит, настоящий темп вдвое быстрее). Затем перебор ±1,5 BPM шагом 0,05 и фазы шагом 4 мс,
  наименьшие квадраты по пикам у каждой доли (±30 мс), выбор «доля или „и“» по басу с серединой.
- **Альтернатива темпа** `alt_bpm`: октавный соперник, если лучший сильнее него меньше чем вдвое; пунктирный — если
  меньше чем в 1,3 раза. `steady` — доли ложатся на сетку точнее 20 мс.
- **Сильная доля** (`structure.rs`): счёт `бас(s) − ½·середина(s) + середина(s+1) + середина(s+3)`; если s и s+2
  ближе 10 % — новизна громкости тактов (квадраты разностей: резкая граница части весит больше размазанной).
- **Удары:** пики онсета всего звука (`peak_pick` донора); бочка — если на ударе прибавился бас: ≥ 20 % прироста
  мощности и не меньше четверти типичного прироста баса (иначе пульсация 808 под хэтом стала бы бочкой). Малый —
  если мощность середины не тише −5 дБ от типичного малого (хэт тише и отсеивается). Мощность, не онсет.
- **Дропы:** такт, где бас громче среднего 4 прошлых на 6 дБ (средние мощности), всё — на 2 дБ, 3 из 4 следующих
  держат уровень; отбор по силе, граница фразы (такт кратен 4) — бонус 3 дБ; первые 4 такта — нет, не ближе
  16 тактов, ≤ 4.
- **Ритма нет** — `NoRhythm`, если доли выделяются меньше чем вдвое (у шума — 0,3, у музыки — 10–17).
- Тесты на синтетике (`tests.rs`): хаус 128 (вступление без бочки, дроп на 17-м такте), лоу-фай 85, трэп 140
  в полутемпе, драм-н-бейс 174, 808 с затуханием, тишина и шум. Хаус: темп ±0,02, каждая доля ±8 мс, бочки и малые 100 % в ±4 мс.

## 2. Хранение — `concat-project/src/beats.rs`

- `BeatGrid` на **медиа**: `extra["cutless"]["beats"]["s<поток>"]` (поток — явный или первый звуковой файла;
  у медиа без описанных дорожек — `default`), всё
  временем файла. На медиа, а не на клипе: копирование клипа не теряет сетку, разрез не плодит копии.
- Команда `SetMediaBeats { media_id, stream, grid }` (`commands/beats.rs`), один шаг undo, NaN отклоняется.
- `file_to_timeline` / `timeline_to_file` — через окно и скорость клипа, с кривой скорости (обратная — делением
  пополам по `SpeedCurve::consumed`). `timeline_picks` — моменты вида под клипом. `head` и `drops` — лёгкое чтение
  без разбора массивов, для окна.

## 3. Агент — `cutless-tools/src/beats.rs`

- `beats_analyze { clip_id, bpm_hint?, again?, wait_seconds? }` — фоновая задача `JobKind::Beats` (кэш — доска задач
  по файлу и потоку; упавшая задача не кэшируется), по готовности сетка ложится командой; ответ — темп, первый такт,
  число тактов, бочек, малых, дропы, подсказка про `bpm_hint` при сомнении. `bpm_hint` выбирает октаву и к готовой
  сетке применяется без нового разбора (такты сохраняются).
- `beats_get { clip_id, what: beats|bars|kicks|snares|drops, from?, to?, every?, offset? }` — секунды таймлайна, ≤ 200.
- `hit_fx { …, on: { clip_id, what, every?, offset?, from?, to? } }` — удары по сетке; моменты вне клипа
  пропускаются, ударов ≤ 128 за вызов.
- `timeline_summary`: `beats 128bpm bar@00:00.420` у клипа с сеткой. Инструкция сервера — порядок эдита по сетке.

## 4. Окно

- Аудиопанель: секция **«Склянки»** (пиратское имя: удары корабельного колокола — мера времени) с кнопкой
  «Отбить склянки», темп в заголовке; анализ на рабочем потоке (`panes/beats.rs`), тост с темпом (и «а может, …»).
  Состояние — глобальный `BeatsState` (`ui/dialogs/beats.slint`).
- Риски на клипе (`ui/timeline/beat-ticks.slint` поверх плёнки и волны, данные — `beat_marks.rs` → поля `beat-*`,
  `drop-a…d` в `ClipData`): такт — высокая `Theme.fade-edge`, доля — короткая `Theme.wave-centre`, если между долями
  ≥ 6 px; такты плотнее 6 px прореживаются вдвое, вчетверо…; дроп — `Theme.wave-hot`. Окно видимости как у плёнки,
  не больше 240 рисок. У клипа с кривой скорости рисок нет.
- Закрытие проекта сбрасывает склянки (и лист пауз): ответ рабочего потока старому проекту отбрасывается.
- Прилипание (`Studio::snapped`): ближайшая доля музыкального клипа; если доли ближе двойного притяжения — только такты.

## Не сделано

- «Залп» по долям (кнопка «на все бочки под клипом») — агенту доступно через `hit_fx.on`, кнопки нет.
- Резка видео по тактам одной кнопкой / инструментом — агент режет `clips_split` по `beats_get bars`.
- Плавающий темп (живая музыка) — одна сетка на трек; `steady = false` предупреждает.
- Размер такта всегда 4/4.
